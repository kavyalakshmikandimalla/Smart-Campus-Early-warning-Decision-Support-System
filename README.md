# 🏫 SMART CAMPUS: EARLY-WARNING AND DECISION-MAKING SYSTEM

## 📌 PROJECT OVERVIEW

The Smart Campus Early-Warning System is a Data Science and Machine Learning based project designed to identify potential risks in a smart campus environment.

The system analyzes three major areas:

- 👨‍🎓 Student Risk
- 🏫 Campus Risk
- 🌦️ Environmental Risk

## 🎯 OBJECTIVES

- Monitor student, campus, and environmental conditions.
- Identify potential risks at an early stage.
- Predict Low, Medium, and High risk levels.
- Identify important risk factors.
- Provide recommended actions.
- Display results through an interactive Streamlit dashboard.
